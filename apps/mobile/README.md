# @nexub/mobile

Private Expo Router showcase for `@nexub/react-native`. It's the component catalogue, the example app, and the target the Maestro flows drive. It is never published.

```bash
pnpm --filter @nexub/mobile ios       # Expo Go in the iOS simulator
pnpm --filter @nexub/mobile android   # Expo Go in an Android emulator
```

See [MOBILE_PLAN.md](../../MOBILE_PLAN.md).
