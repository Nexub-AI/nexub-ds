Prebuilt CSS: `import '@nexub/react/styles.css'` gives you every style the components need (themes, product brands, the utilities they use), so you can use `@nexub/react` without Tailwind. It's all in cascade layers, so your own CSS always wins. Apps already on Tailwind 3 or 4 with the Nexub preset don't need it and keep working as before.
