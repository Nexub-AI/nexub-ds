Opt-in rem layer. Import `@nexub/tokens/css/rem` after `@nexub/tokens/css` (and `@nexub/themes`) and spacing, radius, shape, type sizes, line heights and control heights switch to rem, compact density included. At the default 16px root nothing moves; when a user raises their browser's default font size, text, spacing and controls grow together. Hairlines (1px), capsules, shadows, icon sizes and breakpoints stay in px. rem becomes the default in 3.0; React Native keeps points.
