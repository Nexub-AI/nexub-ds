Opt-in rem spacing and radius. Import `@nexub/tokens/css/rem` after `@nexub/tokens/css` and the spacing, radius and shape variables switch to rem (at a 16px root, so nothing moves by default), so layouts follow the user's browser font size. Hairlines (1px) and capsules stay in px. rem becomes the default in 3.0; React Native keeps points.
