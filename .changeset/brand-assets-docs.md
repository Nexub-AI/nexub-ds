**Brand assets: new "Using the brand assets" docs page.** `@nexub/brand` (shipped in 1.2.0) has the Nexub mark in colour and `currentColor` SVG, the app-icon tile as SVG plus 192 and 512 px PNGs, the Account tile, and `favicon.ico`, all at `@nexub/brand/<file>`. The new docs page (Getting Started → Using the brand assets) covers importing them in a Vite app, copying them into `public/` for `index.html` and the web manifest, plain static serving, and adding a tile for another product.
